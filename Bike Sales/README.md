# 🚴‍♂️ Bike Sales Dashboard in Excel

An interactive and insightful dashboard built in Microsoft Excel to analyze and visualize bike sales data. 

## 📌 Project Overview

The goal of this project is to create a professional dashboard that presents key metrics related to bike sales performance using Excel features like PivotTables, charts, slicers, and conditional formatting.

## 🎯 Features

- 📊 Interactive PivotTables for summarizing data
- 🧮 Key metrics such as total sales, average sales, and region-wise performance
- 📍 Slicers for dynamic filtering by region, product category, and more
- 📈 Charts to visualize sales trends and product distribution
- 🎨 Clean and user-friendly dashboard layout

## 🛠️ Tools Used

- **Microsoft Excel**
  - PivotTables
  - Charts (bar, column, pie)
  - Slicers
  - Conditional Formatting
  - Excel formulas
