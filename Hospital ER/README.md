# 🏥 Hospital Insights Dashboard in Excel

An interactive Microsoft Excel dashboard project designed to analyze and visualize hospital data for better decision-making. 
## 📌 Project Overview

The Hospital Insights Dashboard presents a dynamic and comprehensive overview of hospital operations and patient metrics. It enables users to interact with the data using slicers and filters, identify trends, and monitor key performance indicators.

## 🎯 Features

- 📊 PivotTables for real-time data summaries
- 🎯 KPIs: Patient count, average stay duration, readmission rates, etc.
- 📍 Slicers for filtering by department, gender, age group, and date
- 📈 Interactive charts and graphs to visualize hospital performance
- 🎨 Clean and intuitive layout for ease of analysis

## 🛠️ Tools Used

- **Microsoft Excel**
  - PivotTables
  - Charts (Bar, Line, Pie)
  - Slicers
  - Conditional Formatting
  - Data Cleaning Techniques
